# DiscoveryWorld JEPA Public Transition Probe — Design

Date: 2026-10-09

## Question

Can the existing ECSA `ActionJEPA` learn an action-conditioned predictive
representation from **real, public DiscoveryWorld transitions**, rather than
transitions generated by the three-rule synthetic simulator? Does its predictive
representation contain more heldout action-conditioned information than
training with shuffled action labels, hiding actions, or a simple raw Ridge
regressor?

This is a **representation feasibility experiment**, *not* a claim that JEPA
improves the existing DiscoveryWorld autonomous policy or that it solves
Reactor Lab.

## Existing systems

- Arena A already writes `run.json`, `actions.jsonl` and `observations.jsonl`
  per episode. Reuse these logs; no new benchmark data collection in the v1
  training code.
- The logged observation schema is `pre` with step `t`, action with step `t`,
  and `post` with step `t+1`. The loader verifies alignment.
- Existing `ActionJEPA` already implements learned context encoder, EMA target,
  action-conditioned predictor, variance/covariance regularization. Make its
  action width configurable while preserving the original three-action
  default. Do not create another unrelated JEPA implementation.
- Existing paired `cold/reuse` episodes of **one seed** are correlated, not
  independent training/test environments.

## Public information firewall

Only consume `run.json` metadata for scenario/difficulty/seed, and the two
public log streams. Never open scorecards, action outcome files, hidden world
history, secret crystal parameters or simulator internals. Reject oracle keys
anywhere in the public observation payload if they do appear. Do not derive
training target or representation from official rewards or task scores.

## Features and learning

Use a deterministic, versioned, fixed-length feature hashing baseline over
public JSON tree paths, strings and finite scalars. Sort dictionary keys,
normalize list index paths and bound the number of tokens. Exclude episode
clock fields and unstable observation UUID fields. Hash public action packets
independently, preserving generic action types and argument values. This is
*not* a learned visual/text tokenizer or grounded entity representation.

Train JEPA on `(encoded o_t, encoded a_t, encoded o_{t+1})` without mechanism
labels. Anti-collapse metrics are latent standard deviation and effective
rank. `train_jepa` receives action matrix width determined by the public
feature adapter. No benchmarkspecific action-to-semantic-role dictionary.

## Comparisons

1. Action-conditioned JEPA (normal data).
2. Same JEPA architecture trained with shuffled actions.
3. Same architecture trained and tested with zeroed action input.
4. Ridge regression on the *same* public raw feature sketch and action sketch.

Report per-arm MSE and identity/persistence MSE **in that arm's coordinate
space**, normalized improvement over persistence, and a correct-vs-different-
public-action score. Different neural arms learn different latent coordinate
frames, so raw MSE between arms is not comparable. Alternative action ranking
from an observational log is a predictive diagnostic, not an interventional
causal test.

## Splits and acceptance

- `smoke`: only one recorded episode (such as already collected seed-0/cold),
  chronologically partitioned 60%/20%/20%; label its conclusion as
  `single_episode_temporal_probe_only`. Temporal autocorrelation and a common
  simulator make it nonindependent. It can only validate execution.
- `study`: three or more **distinct scenario seeds**, using only one arm per
  seed. Lower ordered seeds are training, penultimate is validation, final
  is heldout. The heldout seed is never used for training, calibration,
  baseline fitting or model selection.
- A JEPA benefit is *not* established unless the heldout representation
  diagnostics outperform appropriate controls across several novel seeds.
  One study split remains exploratory.
- The existing synthetic ActionJEPA tests and DiscoveryWorld core tests must
  remain valid; malformed log alignment, oracle leakage and seed pseudoreplication
  are rejected.

## Next stage, not in scope

Join a learned representation to `DiscoveryWorldRawEnvironment` and
`ContractExperimentCoordinator` in a **paired interactive** evaluation. That
later experiment measures official task completion, correct predictions,
intervention budget and causal hypotheses; this v1 replay cannot.
